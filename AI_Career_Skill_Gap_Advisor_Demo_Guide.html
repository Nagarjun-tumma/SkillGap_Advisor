1. Executive Overview & Value Proposition

The Problem: Computer Science and Engineering students often face a significant gap between academic curriculum and real-world tech industry expectations.

The Solution: The AI Career Skill Gap Advisor addresses this challenge by fetching and analyzing live job descriptions (such as LinkedIn postings from NVIDIA, Microsoft, etc.), automatically extracting technical skills, identifying missing skill gaps against a student's profile, and generating personalized learning roadmaps.

  • Automated Skill Match Rate: Calculates exact match percentage (e.g. 60% match) for target career roles.
  • LinkedIn Skill Parser: Dynamic NLP algorithm categorizes skills into Required (Must-Have) vs Preferred (Nice-to-Have).
  • Custom Posting Parser: Students can paste any custom LinkedIn job URL or raw job description text.
  • Personalized Roadmaps: Generates step-by-step guided learning paths with estimated timelines and resources.
  • Secure Auth System: Integrated two-factor Email OTP verification system.

3. Application Modules

Module 1: Authentication & OTP Verification

Provides two-factor email OTP validation during registration (/api/auth/send-otp & /api/auth/verify-otp) to ensure authentic student profiles.

Module 2: Student Dashboard & Profile Management

Allows students to set their academic branch, select target roles (e.g., AI/ML Engineer, Full Stack Java Engineer), and manage acquired skills.

Module 3: LinkedIn Job Skill Extraction Engine

Fetches top-tier LinkedIn job postings or parses custom pasted job text (/api/jobs/extract-skills), separating skills into Must-Have (Required) and Nice-to-Have (Preferred).

Module 4: Skill Gap Analyzer & Personalized Roadmap

Computes Match Rate % (acquired_skills / required_skills * 100) and generates sequential learning modules with time estimates.

4. REST API Endpoint Reference

Endpoint Method Description
/api/auth/send-otp POST Generates and emails a 6-digit OTP token for email verification.
/api/auth/verify-otp POST Validates the OTP code entered by the user.
/api/auth/register POST Registers user account in database after OTP verification.
/api/auth/login POST Authenticates email and password, returning session profile.
/api/jobs/linkedin/{roleId} GET Fetches target LinkedIn job posting and extracted skills by role ID.
/api/jobs/extract-skills POST Parses raw job description text or LinkedIn URL to extract skills on the fly.
/api/student/skills/{userId} GET / POST Retrieves or updates student's acquired skill set.

6. Top Examiner Viva Questions & Answers

Q1: What problem does this project solve?
Answer: It bridges the gap between academic education and industry job requirements by analyzing real job descriptions and giving students a personalized roadmap for missing skills.
Q2: How does the LinkedIn Skill Extractor work?
Answer: The backend LinkedInJobService uses keyword parsing and NLP regex matching to extract technical skills and categorize them into Required vs. Preferred based on context clues.
Q3: How is the Match Percentage calculated?
Answer: Match Percentage = (Acquired Required Skills / Total Required Skills in Job Posting) * 100.
Q4: What tech stack is used?
Answer: Frontend uses React.js 18 + Vite with custom styling. Backend uses Java 17 + Spring Boot 3 REST APIs, Spring Data JPA, and MySQL.
Q5: How does the OTP service work?
Answer: Upon request, the backend generates a random 6-digit number, stores it in the OtpToken table with an expiration timestamp, and sends it via email. It is validated before user registration.
